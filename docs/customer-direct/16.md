# Exact money contract — issue #16

The pure module `lib/platform/money.mjs` is independent of browser/provider code. Values are nonnegative safe integer minor units and ISO currency codes supported by the runtime. Decimal strings are parsed with BigInt, never floating multiplication. Zero- and three-decimal currencies have explicit tests. Quote quantities are positive integers; mixed currencies, overflow and excessive precision fail validation.

`calculateQuote` calculates line gross, allocates discount by proportional largest remainders with stable ID ties, computes inclusive/exclusive line tax in basis points with half-up rounding, and adds the already-final shipping amount. Shipping taxation is the delivery/tax adapter's responsibility; no additional tax is inferred here. Quote policyVersion=1 records the calculation contract. Historical order snapshots must retain it.

`pnpm test` verifies allocation sum preservation, tax inclusion, currency precision and invalid quantities. The module is not yet wired into existing checkout. Rollback reverts callers to the prior version only for new quotes; existing snapshots must never be recomputed. No external service, database or UI changes are introduced by this library.

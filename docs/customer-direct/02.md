`pnpm check` runs the Node unit suite, compatibility inventory and Next.js build. A nonzero subprocess exit or a signal fails the runner. `pnpm test:integration` requires CUSTOMER_DIRECT_TEST_DB beginning with customer_direct_test_ and CUSTOMER_DIRECT_TEST_MONGODB_URI; it never falls back to the application database. Tests create disposable synthetic databases and remove only those isolated databases afterward.

The GitHub workflow starts an isolated MongoDB 8.0.26 single-node replica on loopback port 27119, initializes it, and runs real registry/authorization/connection tests. No production secrets are used by database tests. An external protected check must be enforced through repository branch policy before claiming merge prevention; this workflow reports checks but does not silently change repository access policy.

Tests cover actual transaction/idempotency, same-ID cross-database data, revoked membership, superadmin grant expiry, and ciphertext shop binding.
